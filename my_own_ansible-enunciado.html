1.
Crear el escenario de trabajo

    • Proveedor de MV: VirtualBox

  • Basadas en una box de Debian 12.7 preparada para Vagrant

2.
Creación de usuarios de trabajo
  • Creación de un usuario personal en la máquina manager
  • Creación del usuario rut en los equipos node1, node2, node3
  • Configuración de privilegios del usuario rut en los nodos:
    • Todos los privilegios
    • Passwordless sudo
3.
Configuración de SSH
  • Crear par de llaves SSH para el usuario personal en la MV manager
  • Compartir la llave pública del usuario personal del manager con el usuario rut en todos los nodos
4.
Entorno de trabajo
  • Añadir entradas en /etc/hosts del manager con las IPs y nombres de los nodos
  • Configurar el hostname de todas las máquinas virtuales
  • Crear el fichero inventory en el manager con los nombres de los nodos
5.
Scripts de provisionamiento
  • Instalación de paquete — script que instala un paquete en todos los equipos node
  • Uptime de los nodos — script que recolecta el tiempo que llevan encendidos los equipos node
  • Copia de fichero — script que copia un fichero en todos los equipos node
