Montaje de sistemas de ficheros

Cuando ya hemos particionado y estructurado nuestro disco duro con las hereamientas de particionado y sistemas de ficheros, es el momento de poder empezar a utilizarlas. Para poder hacer esto necesitamos que las particiones sean visibles dentro del sistema, y para ello hay que "montarlas".

Este concepto, el montaje de particiones, es lo que nos permite poder acceder a los contenidos de una partición deterninada desde un directorio (punto de montaje) dentro de nuestro sistema FHS

Los puntos de montaje no son más que directorios que creamos para después vincular con alguna de las particiones del disco. La creacióm de estos directorios se realiza con el comando mkdir de la misma forma que se haría con cualquier otro directorio.

Una vez disponemos del punto de montaje sólo queda vincularlo a la partición que queramos. Para ello tenemos 2 opciones:

  • Montaje puntual: utilizamos el comando mount
  • Montaje persistente: utilizamos el fichero fstab

mount

El comando mount nos permite poder relacionar una partición de nuestro disco duro con un directorio del árbol FHS , llamado punto de montaje. Esto se debe a que en los sistemas GNU/Linux se trabaja con un árbol de directorios lógico, sobre una única raíz (/), lo que hace que todos los dispositivos de almacenamiento (particiones, medios extraíbles, etc) se identifiquen con un directorio de este árbol.

Funcionamiento

Para poder utilizar el comando mount lo primero que necesitamos es conocer su sintáxis: 

mount [OPTIONS] DEVICE MOUNT_POINT

donde:
- DEVICE: nombre de la partición
- MOUNT_POINT: nombre del punto de montaje (directorio)

A partir de aquí debemos conocer qué opciones queremos utlizar para el montaje del dispositivo. En el caso de mount podemos diferenciar 3 tipos de opciones:
- Command Line Options
- FS Independent Mount Options
- FS Dependent Mount Options

Command Options

Son las opciones que pasamos por línea de comandos que afectan al comportamiento del comando. Algunas de las más comunes son:

  • -a: monta todos los dispositivos definidos en el fichero fstab
  • -F: (combinado con -a) realiza las operaciones de montaje en procesos paralelos.
  • -l: muestra las etiquetas de las particiones del disco que estan montadas
  • -L: monta una partición (que exista en el fstab ) utilizando su etiqueta (ver ejemplo 1 )
  • -M: cambia el punto de montaje de un dispositivo en caliente
  • -o: permite aplicar opciones de montaje en un dispositivo (separadas por comas)
  • -O: (combinado con -a) permite indicar que los sistemas de ficheros con las opciones especificadas no se deben montar
  • -t: indica el tipo de sistema de ficheros a instalar
  • -T: permite indicar un fichero fstab distinto

Montajes vinculados

Además de las ya comentadas, la opción --bind permite el montaje de un punto de montaje sobre otro. De esta manera podemos acceder a la información de un dispositivo desde 2 ubicaciones distintas. 

$ sudo mount --bind /home/super/public /usr/share/public  

$ ls /home/super/public  
recursos   materials  apunts  

$ ls /usr/share/public  
recursos   materials  apunts

Dispositivos de loop

Con el comando mount también es posible montar un fichero regular como un dispositivo de bloques accesible desde nuestro sistema gracias a la opción loop 

$ ls /mnt

$ sudo mount -o loop /usr/share/data/isos/debian-11.0.0-amd64-netinst.iso /mnt/
mount: /mnt: ATENCIÓN: el dispositivo está protegido contra escritura; se monta como sólo lectura.

$ ls /mnt
autorun.inf  debian  EFI       g2ldr.mbr    isolinux    pool                 README.mirrors.txt  setup.exe
boot         dists   firmware  install      md5sum.txt  README.html          README.source       tools
css          doc     g2ldr     install.amd  pics        README.mirrors.html  README.txt          win32-loader.ini

De esta manera el fichero se ha convertido en una partición más de nuestro sistema, de manera que podemos operar con los datos que incorpora. Esta opción de mount es equivalente al uso del comando losetup

FS Independent Mount Options

Estas opciones de montaje son especialmente útiles para configurar el uso de las particiones de forma automatizada en el inicio del sistema.

Además, algunas de ellas se encuentran definidas por defecto en el kernel del sistema:

Opciones Descripción
async/sync Permite especificar cómo se harán las operaciones de E/S de disco
atime/noatime Define si queremos actualizar o no la marca de tiempo de acceso al fichero
auto/noauto Indica si se puede montar el dispositivo con la opción -a
dev/nodev Permite (o no) la posibilidad
diratime/nodiratime Define si queremos actualizar o no la marca de tiempo de acceso a directorios
exec/no exec Establece si se pueden ejecutar o no los binarios (o ejecutables) del sistema de ficheros
owner/group Permite que un usuario pueda montar un dispositivo si es el propietario de él (ver ejemplo 2
relatime/norelatime Configura la actualización de las marcas de tiempo mtime i ctime
remount Permite volver a montar un dispositivo que ya estaba montado
ro/rw Marca si el sistema de ficheros se monta en lectura o esccritura
suid/nosuid Especifica si se pueden activar o no los bits SUID o SGID
user/nouser Permite indicar si un usuario sin privilegios puede montar (o no) un sistema de ficheros que sólo podrá desmontar él
users Permite indicar que cualquier usuario sin privilegios puede montar un sistema de ficheros y cualquier usuario sin privilegios lo puede desmontar (ver ejemplo 2

FS Dependent Mount Options

En relación a las opciones propias de cada sistema de ficheros, se pueden consultar en el man del comando mount .

De las que hacen referencia a los sistemas ext podemos destacar las siguientes:

Opciones Descripción
acl/no acl activa el uso de POSIX acl
commit= frecuencia de sincronización de los metadatos del journal
data= modo de funcionamiento del journal (data/ordered/writeback)
errors qué hacer en caso de un error en el montaje del sistema de ficheros (continue/remount-ro/panic)
usrquota/grpquota activa las utilidades de gestión de cuotas de disco (ver ejemplo 3 )
nonrecovery/noload no carga el journal durante el montaje (no recomendado)
user_xattr/nouser_xattr habilita los atributos extendidos para usuarios

/etc/fstab 

# /etc/fstab: static file system information.
# Los campos que se definen en este fichero /etc/fstab son los siguientes:
#   - file system: dispositivo que hay que montar
#     - /dev/sdXX
#     - UUID=...
#     - LABEL=[LABEL]
#     - [IP]:[PATH]
#   - mount point: punto de montaje del dispositivo
#   - type: sistema de ficheros de la partición
#   - options: opciones de montaje, separadas por comas
#   - dump: (0|1) indica si se hace una copia (volcado) del sistema de ficheros antes de iniciarse (deprecated)
#   - pass: (0|1|2|...) orden de chequeo del sistema de ficheros en el arranque (0 se omite el chequeo)    
#
# <file system>                            <mount point>   <type>       <options>         <dump>  <pass>
