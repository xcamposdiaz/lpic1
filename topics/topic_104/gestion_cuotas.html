GESTIÓN DE CUOTAS DE DISCO

Los sistemas GNU/Linux permiten gestionar el espacio de una partición de disco con un sistema de cuotas que permite asignar un espacio determinado a cada usuario o grupo del sistema. Estas herramientas vienen dentro del paquete quota proporcionado por los repositorios oficiales de cada distribución.

Los pasos que debemos seguir si queremos aplicar estas cuotas de disco son los siguientes:

Configuración del fichero /etc/fstab

El primer paso consiste en configurar el fichero /etc/fstab para indicar que en el montaje de una partición queremos utilizar cuotas de disco. La configuración seria como la siguiente 

$ tail -1 /etc/fstab
/dev&sdc5  /usr/mount  ext4  async,rw,nouser,noexec,usrquota  0  0

NOTA: Damos por hecho que el punto de montaje ha sido previamente creado mkdir /usr/mount

Generación de la BBDD de cuotas

El siguiente paso consiste en montar el sistema de ficheros configurado y generar la BBDD para la gestión de las cuotas 

$ sudo mount /dev/sdc6
$ sudo quotacheck -u /usr/mount
$ ls /usr/mount
aquota.user

Configuración de las cuotas de disco

El siguiente paso consiste en configurar la cuota asignada a cada usuario o grupo, con el comando edquota . Con este comando vamos a poder definir los valores soft y hard , que indican:
- soft: límite a partir del que se informa al usuario que se acerca a su límite de espacio
- hard: espacio máximo que un usuario (o grupo) puede ocupar en el sistema de ficheros. 

$ sudo edquota -u user 
Filesystem      blocks  soft    hard    inodes  soft    hard  
/dev/sdc6            0  3700    4000         0     0       0

Esta configuración nos indica que el usuario user recibirá un aviso de espacio en disco excedido cuando ocupe 3.7MB de espacio en disco, aunque va a poder seguir almacenando información hasta ocupar los 4MB que marca el límite hard .

Activación del uso de cuotas

Ahora que ya está todo preparado es el momento de activar el uso de las cuotas de disco en el sistema de ficheros a través del comando quotaon , con la opción -u o -g, en función de la cuota que queremos activar 

$ sudo quotaon -u
