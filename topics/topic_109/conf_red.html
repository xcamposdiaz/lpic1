CONFIGURACIÓN DE RED

Sistemas RedHat

En los sistemas Red Hat y derivados la configuración de los parámetros de red se realiza en el directorio /etc/sysconfig/network-scripts/.
Dentro de este directorio existe un fichero "ifcfg-XXX" para cada una de las interfícies del equipo.
Este fichero de configuración consta de los siguientes parámetros: 

# Parámetros relacionados con el dispositivo
DEVICE=ethX    
NAME=[ALIAS]  
HWADDR=[xx:xx:xx:xx:xx:xx]  
ONBOOT=[yes|no]  
BOOTPROTO=[static|dhcp|none]  

# Interfície gestionada por NetworkManager 
NM_CONTOLLED=yes|no  

# Podemos tener más de una IP configurada. Para indicar la máscara lo podemos hacer con NETMASK o PREFIX  
IPADDR0=A.B.C.D  
NETMASK0=A.B.C.D    
GATEWAY0=A.B.C.D  

IPADDR1=A.B.C.D  
PREFIX1=/N  
GATEWAY1=A.B.C.D  

# Parámetros adicionales de red
DOMAIN="your.domain"  
DNS1=A.B.C.D  
DNS2=A.B.C.D  

# Configuración IPv6  
IPV6INIT=[yes|no]  
IPV6_AUTOCONF=[yes|no]  
IPV6ADDR=[xx:xx:xx:xx:xx:xx:xx:xx]  
IPV6_DEFAULTGW=[xx:xx:xx:xx:xx:xx:xx:xx]

Sistemas Debian

En los sistemas Debian y derivados la configuración de las interfícies de red se realiza en el fichero /etc/network/interfaces . Dentro de él se definen todas las targetas del equipo, y se pueden configurar los siguientes parámetros: 

# Configuración mínima necesaria
[auto|allow-hotplug] ethX
iface eth1 inet [static|dhcp]
  address A.B.C.D        # si hemos escogido "static"
  netmask A.B.C.D        # si hemos escogido "static"

# Otros parámetros de configuración
  network A.B.C.D
  broadcast A.B.C.D
  gateway A.B.C.D
  dns-nameservers A.B.C.D
  pre-up [COMMAND]
  up [COMMAND]
  post-up [COMMAND]
  pre-down [COMMAND] 
  down [COMMAND]
  post-down [COMMAND]

# Segunda dirección IP de la interfície
auto eth1:1
iface eth1:1 inet static
  address 10.0.0.12
  netmask 255.255.255.0
